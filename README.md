# nrland — Skill Claude « Analyse de profil »

Un skill gratuit pour Claude qui analyse ton compte **Instagram, TikTok ou Snapchat** :

- il trouve ta niche (ou t'en propose 3),
- il réécrit ta bio,
- il repère ce qui marche et ce qui bloque,
- il te donne 10 idées de posts prêtes à tourner,
- il te fait un plan d'action sur 30 jours pour grandir et monétiser.

## Installation

1. Télécharge ce dépôt : bouton vert **Code** → **Download ZIP**.
2. Dézippe-le, puis recompresse uniquement le dossier `analyse-profil` en `.zip`.
3. Sur claude.ai : **Paramètres** → **Fonctionnalités** → section **Skills** → **Importer un skill**, puis choisis le `.zip`.
4. Active le skill.

## Utilisation

Dans une nouvelle conversation avec Claude, écris par exemple :

> Analyse mon compte Instagram @tonpseudo. Mon objectif : vendre mes services de coaching.

Tu peux aussi envoyer des captures d'écran de ton profil et de tes stats : l'analyse sera plus précise.
